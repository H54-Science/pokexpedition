# Pokémon menu icons

83 transparent PNG icons extracted from the first square frame of the Front sprite sheets supplied by the project owner. Original sprite sheets were not modified. Dimensions and source frame counts are recorded in frames.json.

The UI uses image-rendering: pixelated. src/ui/art.js maps species keys to these files. Shiny capture results keep the existing shiny 3D portrait rendering, so their colors remain accurate.

The theatre scenery and decorative icons in src/ui/theatre.js are original SVG artwork. No Genshin screenshots or UI assets are bundled.
